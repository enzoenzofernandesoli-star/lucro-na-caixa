<Objetivo>
Ao final você entende as peças que precisam estar prontas antes do primeiro anúncio: conta de anúncios, página, pixel e API de Conversões, e quais eventos enviar.
</Objetivo>

<PorQue>
Anúncio de venda na Meta aprende com as compras. Se o site não avisa à Meta quando alguém compra, a plataforma não sabe para quem mostrar o anúncio nem você sabe o resultado. A maior parte dos "anúncios que não funcionam" de iniciantes começa com medição quebrada.
</PorQue>

## Explicação

### 1. As peças

- **Página** no Facebook e conta no Instagram da loja.
- **Portfólio empresarial** (gerenciador de negócios), que reúne página, conta de anúncios, pixel e acessos de pessoas.
- **Conta de anúncios** com forma de pagamento.
- **<Termo id="pixel">Pixel</Termo>** instalado no site.
- **<Termo id="api-de-conversoes">API de Conversões</Termo>** enviando os mesmos eventos pelo servidor.

### 2. Pixel e API de Conversões

- A Meta recomenda que quem compartilha eventos pelo pixel use também a API de Conversões, para melhorar o desempenho e a mensuração. [verificado]
- Os dados da API de Conversões são menos afetados por erros de carregamento do navegador, problemas de conexão e bloqueadores de anúncios. A melhor prática é usar a API **junto** com o pixel. [verificado]
- A API não serve para contornar políticas de compartilhamento de dados. [verificado]

Muitas plataformas de loja oferecem integração pronta com o pixel e a API: confira na sua.

### 3. Os eventos de e-commerce

| Evento | Quando dispara |
| --- | --- |
| Ver conteúdo | Alguém abre a página de produto |
| Adicionar ao carrinho | Clica em comprar/adicionar |
| Iniciar finalização | Entra no checkout |
| Compra | Pedido concluído, **com valor e moeda** |

O evento de compra com valor é o que permite calcular ROAS e otimizar para vendas.

### 4. LGPD

Pixel e API tratam dados de quem visita a loja. Explique esse uso na política de privacidade (LGPD, art. 9º) e tenha base legal para ele (art. 7º). [verificado] Peça orientação jurídica para o banner de cookies da sua loja.

<Exemplo>
Conferência de medição de uma loja (situação de exemplo): 100 pedidos no mês segundo a loja; o Gerenciador de Eventos mostrou **62 compras** pelo pixel e **96** depois de ativar a API de Conversões junto. Sem a API, a campanha "via" só 62 vendas e otimizava com menos informação.
</Exemplo>

<ErroComum>
**Anunciar para vendas sem o evento de compra funcionando.** A plataforma otimiza no escuro e você não sabe o CPA real.

**Instalar o pixel em site que não é seu.** A Meta orienta não colocar o pixel associado à sua conta em sites que não são seus sem permissão. [verificado]

**Mandar informação proibida nos eventos.** A Meta proíbe compartilhar dados de saúde, financeiros ou de crianças pelo pixel; revise nomes de eventos, parâmetros e URLs. [verificado]
</ErroComum>

<NaPratica>
Faça uma compra de teste na sua loja (ou acompanhe uma) e confira, no Gerenciador de Eventos, se os quatro eventos apareceram, com valor na compra. Compare as compras medidas na semana com os pedidos reais.
</NaPratica>
